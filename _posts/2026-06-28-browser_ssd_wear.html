Tarayıcılar ve SSD ömrü: gizli aşındırıcılar

Firefox 15 saniyede bir disk yazar. Chrome yerel AI modelini arka planda indirir. Electron uygulamaları log'larını asla durdurmaz. Bunların hiçbirini fark etmezsiniz — ta ki SMART verisi konuşana kadar.

Modern SSD'lerde NAND flash hücrelerinin sınırlı yazma dayanımı vardır. Üretici bu değeri TBW (Total Bytes Written) olarak garanti belgesi üzerinde belirtir. Garanti, TBW aşıldığında genellikle geçersiz sayılır. Sorun şu: ortalama bir geliştirici makinesinde tarayıcılar, Electron uygulamaları ve önbellek mekanizmaları sessiz sedasız TBW'yi aşıyor.

Firefox: 15 saniyede bir storage.sqlite

Firefox, tarama oturumu verilerini $PROFILE/storage.sqlite dosyasına varsayılan olarak her 15 saniyede bir yazar. Bu davranış browser.sessionstore.interval parametresiyle kontrol edilir.

# Linux — Firefox profil dizinindeki yazmaları izle
inotifywait -m -r ~/.mozilla/firefox/*.default-release \
  -e close_write --format '%T %w%f %e' --timefmt '%H:%M:%S' | \
  grep -E 'sqlite|json|jsonlz4'

# Çıktı örneği:
# 14:32:15 /home/user/.mozilla/firefox/xxxxx/storage.sqlite CLOSE_WRITE
# 14:32:30 /home/user/.mozilla/firefox/xxxxx/storage.sqlite CLOSE_WRITE
# 14:32:45 /home/user/.mozilla/firefox/xxxxx/storage.sqlite CLOSE_WRITE
# Windows — PowerShell ile yazma zamanı farkı
$before = (Get-Item "$env:APPDATA\Mozilla\Firefox\Profiles\*\storage.sqlite").LastWriteTime
Start-Sleep 60
$after = (Get-Item "$env:APPDATA\Mozilla\Firefox\Profiles\*\storage.sqlite").LastWriteTime
"Son yazma farkı: $(($after - $before).TotalSeconds) saniye"

Firefox optimizasyon ayarları (about:config)

# Session kayıt intervalini artır (ms) — varsayılan: 15000
browser.sessionstore.interval = 60000

# Disk cache'i kapat, RAM cache kullan
browser.cache.disk.enable = false
browser.cache.memory.enable = true
browser.cache.memory.capacity = 524288  # 512MB

# SQLite WAL checkpoint periyodunu uzat
storage.sqlite.wal-checkpoint-interval = 3600000  # 1 saat

# Media cache disk'e yazmasın
media.cache_size = 0
media.cache_readahead_limit = 0
places.sqlite ve WAL modu: Firefox geçmiş ve yer imleri için SQLite WAL (Write-Ahead Logging) kullanır. WAL checkpoint işlemleri yoğun disk yazmasına neden olabilir. WAL dosyası büyüdükçe checkpoint sıklaşır. PRAGMA wal_checkpoint(TRUNCATE) komutu ile elle tetiklenebilir.

Chrome: Gemini Nano ve yerel AI indirmesi

Chrome 127+ ile birlikte Google, Gemini Nano modelini kullanıcıya bildirmeden yerel depolama alanına indirir. Model boyutu 1.7-3.5 GB arasında değişir.

OptimizationGuide: Chrome'un optimizasyon rehberi servisi (chrome://optimization-guide-internals) sayfa yükleme tahminleri için arka planda veri indirir ve yazar. Kurumsal ortamlarda OptimizationGuideFetchingEnabled: false policy'si disk yazmasını belirgin şekilde azaltır.

VS Code, Slack, Discord, Teams — hepsi Chromium tabanlı Electron framework'ü üzerinde çalışır. Her biri kendi log mekanizmasını ayrı ayrı yönetir.

# Linux — uygulamaların disk yazmasını izle
sudo iotop -ao -d 5 | grep -E 'chrome|code|slack|teams|discord'

# dstat ile saniyede yazma miktarı
dstat -d --top-io-adv 5

# Windows — process bazlı IO istatistikleri
Get-Process | Sort-Object -Property WorkingSet -Descending |
  Select-Object Name,
    @{N='IO Write (MB)';E={[math]::Round($_.IOWriteOperationCount/1MB,2)}} |
  Format-Table -AutoSize

# smartctl ile TBW durumu (NVMe)
sudo smartctl -a /dev/nvme0 | grep -E 'Data Units Written|Total Bytes Written'

Çözümler: RAM disk ve tmpfs

Linux — tmpfs ile profil (psd)
Tarayıcı profilini ve cache'i RAM üzerine mount et. profile-sync-daemon (psd) bunu otomatize eder ve kapatma sırasında diske sync eder.
Disk yazması %80-95 azalır
Windows — ImDisk RAM disk
ImDisk Toolkit ile sanal RAM disk oluştur. Tarayıcı cache dizinini sembolik link ile RAM disk'e yönlendir.
Cache yazmayı tamamen ortadan kaldırır
Firefox about:config
Disk cache'i kapat, sessionstore intervalini artır, WAL checkpoint periyodunu uzat.
%60-70 yazma azalması
Chrome enterprise policy
Gemini Nano, OptimizationGuide ve crash reporter'ı policy ile devre dışı bırak.
1-3 GB model indirmesini engeller 
# Linux — profile-sync-daemon kurulumu
sudo pacman -S profile-sync-daemon   # Arch
sudo apt install profile-sync-daemon # Debian/Ubuntu

# ~/.config/psd/psd.conf
BROWSERS=(firefox chromium)
USE_OVERLAYFS="yes"

systemctl --user enable psd
systemctl --user start psd
psd p  # durum kontrolü
# Linux — manuel tmpfs cache (/etc/fstab)
tmpfs /home/user/.cache/mozilla      tmpfs uid=1000,gid=1000,size=512M,mode=0700 0 0
tmpfs /home/user/.cache/google-chrome tmpfs uid=1000,gid=1000,size=512M,mode=0700 0 0

# Windows — ImDisk ile sembolik link
# 1. ImDisk ile R: sürücüsü oluştur (512MB)
imdisk -a -s 512M -m R: -p "/fs:ntfs /q /y"

# 2. Chrome cache'i yönlendir
$cache = "$env:LOCALAPPDATA\Google\Chrome\User Data\Default\Cache"
Remove-Item $cache -Recurse -Force
New-Item -ItemType SymbolicLink -Path $cache -Target "R:\ChromeCache" -Force
RAM disk riski: Tarayıcı profili RAM disk'te tutulurken sisteminiz beklenmedik şekilde kapanırsa (güç kesintisi, BSOD) o oturumun verileri kaybolabilir. profile-sync-daemon bu riski overlay FS ile minimize eder. Windows'ta ImDisk kullanıyorsanız düzenli sync veya UPS kesinlikle önerilir.

Genel SSD koruma kontrol listesi

  • ✓CrystalDiskInfo (Windows) veya smartctl (Linux) ile TBW durumunu aylık kontrol et
  • ✓Firefox disk cache'ini kapat, RAM cache'i 512MB olarak ayarla
  • ✓Chrome'da Gemini Nano ve OptimizationGuide policy ile kısıtla
  • ✓Teams log dizinini periyodik olarak temizle veya log seviyesini düşür
  • ✓Linux'ta psd veya tmpfs mount ile tarayıcı cache'ini RAM'e taşı
  • ✓Windows'ta ImDisk ile cache için RAM disk oluştur
  • ✓Geliştirici makinesinde SSD'nin TBW garantisini not al; %80 dolduğunda değiştirmeyi planla
  • ✓Docker build cache ve npm/pip cache dizinlerini SSD yerine HDD'ye yönlendir
